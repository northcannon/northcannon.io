# NorthCannon.io

Public site for NorthCannon: a static Astro build with no browser JavaScript.

Only claims with an approved, founder-attested lifecycle render on production
routes. See [public conceptual direction](docs/public-conceptual-direction.md)
for the site's guiding principles, and `CONTRIBUTING.md` for how content and
changes are governed and validated.

## Building

```sh
npm ci --ignore-scripts
npm run build
```

See `CONTRIBUTING.md` for the full validation suite required before merging.
