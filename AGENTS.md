# Public repository agent instructions

Work only in this public repository. Do not access or import private repositories,
private artifacts, secret files, or credentials. Publish invariants, not mechanisms.

The founder-approved implementation envelope governs scope. Preserve the existing
palette and approved text. These are permanent rules, not a record of any specific
change.

Use Astro, TypeScript, Tailwind, and static output. No browser JavaScript, inline
scripts/styles, external resources, forms, analytics, cookies, or tracking.
Only `dist/` is a prospective publication artifact. Never deploy the repository root.

Run `npm run check` and `npm audit` before handoff. Public factual claims require
founder-approved copy and governance metadata (see the "Public claims" section of
`CONTRIBUTING.md`). A successful test is not content approval or proof of deployed
security. No merge or publication without founder review; preserve independent
acceptance review.
